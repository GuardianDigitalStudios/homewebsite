The index is a number, not an emojiEach card opens with a zero-padded 01–04 in mono, accent-coloured, via .value .idx. An earlier version of this page described a decorative emoji per card as droppable. There is no emoji. The number is the only ornament, and the sequence is the reason it reads as a set.
Card 04 sets the width of all four — do not put another unbreakable string in one hello@guardiandigitalstudios.com is 240px of text with no break opportunity, which made card 04's min-content 244px, which made every card 310px once .values collapsed to one column, which scrolled the whole page sideways below 334px.

Held off by overflow-wrap:anywhere on .value. It has to be anywhere and not break-word, because only anywhere feeds back into intrinsic sizing, and intrinsic sizing is the entire problem. A URL, a package name or a second address in any card re-opens this.

Titles are h3, and the size is set here rather than inheritedThese were h4 because 19px looked right, which skipped a level under the section's h2. They are h3 now with .value h3{font-size:var(--step-1)} holding the same 19px. Heading levels are levels, not sizes.
