Mobile
Hamburger toggles a full-width panel; links close it on tap
The mobile panel has a hard ceiling, and it is a count of linksnav ul.open animates to max-height:260px, because auto cannot be transitioned. Each link is roughly 51px, so four fit in 204px and there is room for one more. A sixth link silently clips. Raise the value in the same commit that adds the link.

When checking this, do not read max-height in the tick the class is added — it returns 0px, because that is the animation's first frame. The menu has been reported broken twice on that basis while working correctly.

States
  • Default. There is no scrolled state: the bar is translucent and blurred at every position, so the scrolled class had nothing left to change and its scroll listener was removed
  • Link hover / focus, focus must be visible, it is keyboard-reachable
  • Current page, via aria-current
  • Mobile menu open / closed
